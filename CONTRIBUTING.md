Thank you for your interest in contributing.

## Developer Certificate of Origin

Every commit must be signed off to certify that you have the right to submit the work under
the project's license, per the [Developer Certificate of Origin 1.1](https://developercertificate.org/):

```
git commit -s
```

This adds a `Signed-off-by: Your Name <you@example.com>` trailer to the commit message.
Use a real name and an address you control. Pull requests with unsigned commits will be
asked to add the sign-off before review.

## Third-party code

Do not copy code into this repository unless its license is compatible with Apache 2.0
(for example MIT, BSD, Apache 2.0). Keep the original copyright notice, and record the
source and license in the NOTICE file when the upstream license requires attribution.

## Work done for an employer

If you contribute as part of your job, make sure your employer permits it. Many employment
agreements assign work-related inventions to the employer; a contribution made on company
time or equipment may need your employer's written approval.

## Proposing changes

1. Open an issue describing the change you have in mind, unless it is trivial.
2. Fork the repository and create a branch from `main`.
3. Keep commits focused and signed off.
4. Open a pull request and describe what changed and why.
